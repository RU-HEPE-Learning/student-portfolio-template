# Evidence Traceability Guide

For each portfolio item, maintain a clear chain:

**Task → Evidence → Reflection → Feedback → Final Artifact**

A complete trace should answer:
- Which assignment produced this artifact?
- What evidence supports completion?
- Where is the student's reflection?
- Where is the instructor feedback?
- Which file is the final portfolio version?

Do not fabricate missing evidence. If a link in the chain does not exist, leave it blank or mark it pending.
