# RU-HEPE Student e-Portfolio Template

Reusable student e-Portfolio structure for RU-HEPE courses and the HED3505 GitHub Learning Hub.

## Canonical portfolio flow

**Activity → Evidence → Reflection → Feedback → Final Portfolio Artifact**

## Core sections

- `profile.md` — minimal student/course context
- `PORTFOLIO-INDEX.md` — evidence and completion index
- `evidence/` — learning artifacts and approved evidence
- `reflections/` — structured reflections
- `feedback/` — instructor feedback records
- `final/` — final accepted portfolio artifacts

## Evidence principles

Evidence should be:
- authentic;
- traceable to a learning task;
- relevant;
- clearly named;
- separated from interpretation and reflection.

## Privacy

Student portfolio repositories should be private by default.

Do not commit:
- student ID numbers unless explicitly required and authorized;
- private contact information;
- health information;
- official grades;
- confidential school data.

## Completion logic

A portfolio artifact should be moved or copied into `final/` only when the related learning task has reached **COMPLETE** status.
