# RU-HEPE Student e-Portfolio Template

Reusable student e-Portfolio structure for RU-HEPE courses.

## Core sections
- `profile.md` — student/course context
- `evidence/` — learning artifacts and evidence
- `reflections/` — structured reflections
- `assessment/` — feedback and assessment records

## Evidence principles
Evidence should be authentic, traceable, relevant to the learning task, and clearly distinguished from interpretation or reflection.

## Privacy
Do not commit sensitive personal, health, or confidential data to a public repository. Use de-identified or instructor-approved evidence only.
